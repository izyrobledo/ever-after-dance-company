# Ever After Dance Company

Marketing website for Ever After Dance Company, a wedding dance instruction business offering private couple's lessons, group/wedding party choreography, and day-of support in Orange County & Los Angeles.

**Live site:** [everafterdancecompany.com](https://everafterdancecompany.com) *(pending deployment)*

## Stack

Plain HTML, CSS, and vanilla JavaScript — no build step or framework required.

## Structure

- `index.html` — page markup (hero, about, services, testimonials, contact)
- `styles.css` — styling
- `script.js` — nav toggle, footer year, contact form handling
- `images/` — site imagery

## Running locally

Open `index.html` directly in a browser, or serve it locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
